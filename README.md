# 🌪️ Double Pendulum Chaos Simulation

This project simulates a **double pendulum system** using numerical integration and demonstrates **chaotic motion**, which is highly sensitive to initial conditions.

It also computes an approximate **Lyapunov exponent**, visualizes **phase space**, checks **energy conservation**, and includes a **live animation** of the system.

---

## 🚀 Features

- 📌 Realistic double pendulum physics simulation  
- 📈 Phase space visualization (θ vs ω)  
- 🔥 Chaos analysis using Lyapunov exponent  
- ⚡ Energy conservation plot  
- 🎞️ Real-time animation of pendulum motion  

---

## 🧠 Physics Behind It

The double pendulum is a classical nonlinear system governed by coupled differential equations.  
Small changes in initial conditions lead to drastically different motion — a hallmark of **chaos theory**.

---

## 📊 Outputs

- Phase space plot  
- Energy vs time graph  
- Animation of motion  
- Lyapunov exponent value (measure of chaos)
